# IBM Python Project

A collection of Python and data science projects completed as part of IBM coursework.

## Contents

- **DataScienceEcosystem.ipynb** - Introduction to the Python data science ecosystem and core libraries
- **DataScienceEcosystem (1).ipynb** - Extended exploration of data science tools and frameworks
- **Final Assignment.ipynb** - Comprehensive final assignment demonstrating applied data science concepts

## Overview

This repository contains Jupyter notebooks covering fundamental concepts in the Python data science ecosystem, including data manipulation, analysis, and visualization techniques. The projects progress from foundational knowledge through advanced applications.

## Technologies

- Python 3.7+
- Jupyter Notebook
- Data science libraries:
  - pandas - Data manipulation and analysis
  - NumPy - Numerical computing
  - matplotlib - Data visualization
  - scikit-learn - Machine learning library

## Requirements

- Python 3.7 or higher
- pip package manager

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shivani-vishwakarmaa/IBM-Python-Project.git
   cd IBM-Python-Project
   ```

2. Install required dependencies:
   ```bash
   pip install jupyter pandas numpy matplotlib scikit-learn
   ```

3. Open notebooks in Jupyter:
   ```bash
   jupyter notebook
   ```

4. Navigate to the desired notebook file and open it in your browser.

## Project Structure

- `DataScienceEcosystem.ipynb` - Covers Python fundamentals and introduction to data science libraries
- `DataScienceEcosystem (1).ipynb` - Advanced topics including data transformation and analysis
- `Final Assignment.ipynb` - Practical application of learned concepts with real-world data

## Learning Outcomes

Upon completing these projects, you will understand:

- Python fundamentals and best practices
- Data manipulation using pandas
- Numerical operations with NumPy
- Data visualization with matplotlib
- Basic machine learning concepts
- Jupyter notebook development workflow
