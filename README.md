# IBM Python Project

A collection of Python and data science projects completed as part of IBM coursework.

## Contents

- **DataScienceEcosystem.ipynb** - Introduction to the Python data science ecosystem and core libraries
- **DataScienceEcosystem (1).ipynb** - Extended exploration of data science tools and frameworks
- **Final Assignment.ipynb** - Comprehensive final assignment demonstrating applied data science concepts

## Overview

This repository contains Jupyter notebooks covering fundamental concepts in the Python data science ecosystem, including data manipulation, analysis, and visualization techniques.

## Technologies

- Python
- Jupyter Notebook
- Data science libraries (pandas, NumPy, matplotlib, etc.)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shivani-vishwakarmaa/IBM-Python-Project.git
   ```

2. Install required dependencies:
   ```bash
   pip install jupyter pandas numpy matplotlib
   ```

3. Open notebooks in Jupyter:
   ```bash
   jupyter notebook
   ```
